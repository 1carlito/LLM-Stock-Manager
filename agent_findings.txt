=== Backtest Performance Analysis ===


This analysis compares the performance of three different LLM agents (GPT, Claude, and Gemini) on the same stock trading backtest from June 12 to August 29, 2025.

Methodology:
- Initial Portfolio Value: $1,000,000
- Risk-Free Rate: 5.5% (annual)
- Trading Universe: GOOGL, NVDA, PLTR, ABBV, TMO, UNH, JPM
- Data Source: FMP API (historical prices, financials, news)

Metrics Explanation:
1. Cumulative Return (CR): Total percentage return over the entire period
2. Annualized Return (AR): Return normalized to annual basis
3. Sharpe Ratio (SR): Risk-adjusted return relative to risk-free rate
4. Maximum Drawdown (MDD): Largest peak-to-trough decline
5. Volatility: Annualized standard deviation of returns
6. Win Rate: Percentage of days with positive returns

Formula Details:
CR = (Vend - Vstart) / Vstart × 100%
AR = ((Vend/Vstart)^(1/N) - 1) × 100%
SR = (R̄ - Rf) / σ
MDD = max(Peak - Trough) / Peak × 100%


Notes:
- All returns are calculated using daily portfolio values
- Sharpe ratio uses daily returns scaled to annual basis
- Maximum drawdown considers daily portfolio values
- Transaction costs and slippage are not included
